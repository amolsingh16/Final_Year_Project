1. Executive Summary & Core Audit Findings

Architecture Evolution

Transitioned from a single 3-block CNN baseline (134 MB) to a 4-Model Ensemble incorporating transfer-learning MobileNetV2 backbones, 5-view Test-Time Augmentation (TTA), and a 4,648-D deep botanical leaf verifier. Neither ResNet nor EfficientNet is present in the codebase.

Accuracy Status Verification

The commit message e4ff111 claims "95% acc", and UI counters show 92%. However, no evaluation logs, classification reports, or confusion matrices exist on disk. The 95% figure remains an unsubstantiated developer claim.

Botanical Gate Verification

A 4-stage filter (verify_is_tomato_leaf) combines metadata keywords, HSV/Excess Green Index (ExG), leaf blade elongation aspect ratios, and logistic regression nearest exemplars to safeguard against non-tomato leaf uploads.

Confidence Post-Processing Floor

In disease_service.py, any prediction with <91.2% confidence is artificially clamped to 91.2% – 98.6% using a custom formula, masking model uncertainties.

🎯 Concise Viva Voce Defense Answers

Q1: Which model did we use before?

A single, custom Sequential 3-Block Convolutional Neural Network (Conv2D: 32 → 64 → 128 → Dense: 128 → Dropout: 0.5 → Dense: 10), preserved in plant_disease_model_original_backup.h5 (134 MB).

Q2: Which model or models are we using now?

A 4-Model Ensemble combining 3 transfer-learning MobileNetV2 variants (m_focal, m_main, m_seg) and the baseline 3-Block CNN (m_orig), plus a 4,648-D LogReg botanical verifier.

Q3: What techniques were added to improve accuracy?

Transfer learning with MobileNetV2 backbones, multi-model weighted soft voting (0.48, 0.30, 0.14, 0.08), 5-view Test-Time Augmentation (TTA), LAB CLAHE histogram contrast sharpening, temperature scaling (T=0.24), and a 4-stage botanical & species verification gate.

Q4: What was the previous verified test accuracy?

Not verified from available evidence. UI displays showed 98% or 92%, but no evaluation log was preserved in repository artifacts.

Q5: What is the current verified test accuracy?

Not verified from available evidence. The commit message asserts "95% acc", but no evaluation output log or confusion matrix exists in the repository.

Q6: What is the actual measured improvement?

Not verified from available evidence. Architectural improvements are fully implemented and functional in code, but empirical percentage gains cannot be certified without running the evaluation script across the 3,203 test images.
